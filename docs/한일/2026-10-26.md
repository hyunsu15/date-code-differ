# 2026-10-26 — 모두 동일할 때 안내 · SSH 연결 중 문구 · 일주일 프리셋

## 왜

- 바뀐 파일이 하나도 없으면(배포 없던 날끼리) 동일한 파일은 목록 맨 아래에 접혀 있어, 본문이 "비교할 파일을 고르세요" 로 남았다 — 고를 것이 없는데 고르라는 말.
- SSH 로 날짜를 읽는 동안 "`npm run dev` 터미널을 보라" 는 안내가 떴다 — 화면을 쓰는 사람에게는 필요 없는 말이라는 요청.
- 날짜 칸 왼쪽에 "최근 일주일" 을 한 번에 고르는 프리셋 요청.

## 무엇을 했나

- **모두 동일 안내** `AllSameNotice` — "바뀐 파일이 없습니다 · 견준 파일 N개가 모두 동일합니다" + 펼치는 법 + `▾ 동일한 파일 N개 펼치기` 버튼(목록을 숨겨도 펼칠 수 있게).
  제외로 접힌 것이 있으면 "N개는 세지 않았습니다" 를 붙인다. 스키마 탭도 같은 안내(테이블) — 없어진 "변경된 테이블만" 체크를 가리키던 문구도 걷어냈다.
- **SSH 로딩 문구** — 가운데 제목·목록 요약 모두 "SSH 연결 중…", 본문은 "`계정@서버 경로` 에 연결하고 있습니다." 만. 폴더는 예전 그대로.
- **일주일 프리셋** `weekAgoSelection` — 이후 = 대상 최신, 이전 = 그 7일 전 시점(폴더가 없으면 그 앞 가장 가까운 날짜, 일주일보다 짧으면 가장 오래된 날짜).
  지금 쌍이 그것이면 버튼이 켜진 모양. 툴팁에 고를 쌍을 미리 적는다. 코드·스키마 탭 공용.
- 헤더 자리: 버튼(56px) 때문에 1024 · 1181~1450px 에서 헤더가 두 줄로 밀렸다 → 1180px 이하는 환경 묶기·새로고침을 아이콘만,
  앱 이름 접는 폭 1280→1350px, 폴더 이름 접는 폭 1380→1450px. 1024 · 1181 · 1190 · 1351 · 1390 · 1451px 에서 한 줄 확인.
- 확인: 예시 폴더 운영 09-01 → 09-05(동일) 에서 안내 · 버튼 펼치기, 스키마 08-01 → 08-15 에서 테이블 안내, SSH 프리셋에서 "SSH 연결 중…", 일주일 = 08-15 → 09-05.
- 테스트: `selection.test.ts` 일주일 6건(달·해 넘김, 정확히 7일 전, 빈 날, 짧은 목록, 날짜 아닌 폴더, 다른 환경). 전체 517개 통과.
- 사용설명서(2장 일주일 절 · 4장 모두 동일 절 · 7-5), README 화면 구성, 도움말, 스크린샷 03-picker(⑦) · 14-allsame 새로.

# 2026-10-26 — 일주일 프리셋 → "지난주" (지지난주 금요일 → 지난주 금요일)

- 사용자 요청: 일주일 버튼을 지지난주 금요일 ~ 지난주 금요일로, 이름도 그에 맞게. 이름은 **지난주** 로 했다 (헤더 자리상 세 글자, 정의는 툴팁에).
- `lastWeekRange(today)` — 주는 월~일, 오늘(로컬 시계) 기준. 10-26(월) · 10-30(금) · 11-01(일) 모두 10-16 → 10-23.
  `lastWeekSelection` — 각 금요일 시점(그날 폴더가 없으면 그 앞 가장 가까운 날짜). 같은 곳인데 두 금요일 사이 폴더가 없으면 버튼을 잠근다.
- 툴팁: `지난주: 10-16(금) → 10-23(금)` + 고를 날짜(또는 못 고르는 이유). 예시 폴더는 09-05 가 마지막이라 오늘 기준으론 잠긴다 —
  시계를 09-07 로 속여 08-15 → 09-01 이 골라지고 버튼이 켜지는 것 확인.
- 테스트: 지난주 7건(요일별 범위 · 해 넘김 · 빈 금요일 · 짧은 목록 · 변경 없는 주 · 날짜 아닌 폴더 · 다른 환경). 전체 519개 통과.
- 사용설명서 2장 절 교체, README · 도움말 · 03-picker 스크린샷 갱신. 외부 API 변경 없음.

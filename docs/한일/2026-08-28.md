# 2026-08-28

## 1. 저장소 초기 커밋 (기능 단위 18개)

`git init` 만 돼 있고 커밋이 하나도 없던 상태라, 전체를 **기능 단위로 쪼개** 히스토리를 만들었다.
한 커밋에 전부 넣으면 나중에 "이 파일이 왜 이렇게 됐는지" 를 되짚을 수 없어서다.

```
chore  프로젝트 뼈대 → feat  설정 파일 → 공용 타입 → diff 엔진 → 공유 유틸
     → 소스 계층(로컬 → SSH) → ssh-login CLI → 서버 API
     → 화면(위치 설정 → 날짜 선택 → 파일 목록 → diff 뷰어 → 앱 셸)
     → test → 예시 폴더 → docs → 배포 스크립트
```

- 순서는 **의존 방향**을 따랐다 (`src/lib` → `server` → `src/features` → `App`).
- `change/config.ts` 는 `.gitignore` 대상이라 들어가지 않았다 (템플릿만 커밋됨).
- 커밋 대상에 서버 주소·계정·비밀번호가 없는지 확인했다.

## 2. 폴더 접두사 프리셋 (신규)

한 폴더에 환경별 스냅샷이 **이름으로 섞여** 쌓이는 현장을 위해,
`prod` / `test` / `dev` 를 골라 날짜 목록을 좁히는 기능을 넣었다.

```
/home/deploy/release/
├─ prod_20260801/  prod_20260901/     ← [운영] 을 고르면 이 둘만
├─ test_20260801/
└─ dev_20260901/
```

### 정한 것

| 갈림길 | 정한 것 | 이유 |
| ------ | ------- | ---- |
| 접두사를 어디서 거를까 | **서버** (`listSnapshots`) | 스냅샷마다 파일을 훑는 게 비싼 쪽이다. 화면에서 거르면 안 볼 폴더까지 다 훑고 버리게 된다 (SSH 면 폴더당 `find` 한 번) |
| 목록은 어디에 둘까 | `change/config.ts` 의 `FOLDER_PREFIXES` | 위치 프리셋과 같은 자리. 파일이 진실이라 고치면 바로 반영된다 |
| 고른 값은 어디에 | localStorage (`cd-prefix`) | 서버는 상태를 두지 않는다 — 요청마다 `prefix` 쿼리로 보낸다 |
| 기본값 | `'all'`(전체) | 복사하자마자 폴더가 숨는 건 놀랍다. 켜는 건 사용자가 고를 때 |
| 화면 위치 | 헤더, 날짜 칸 **왼쪽** | 날짜 목록을 좁히는 값이라 날짜 선택 옆이 맞다. 옵션 바(표시 옵션)와는 성격이 다르다 |
| 환경이 폴더로 나뉜 경우 | **지원하지 않음** | `release/prod/20260801` 구조는 환경별 `SOURCE_PRESETS` 항목으로 이미 된다. 같은 일을 두 갈래로 만들지 않았다 |

- 대소문자는 구분하지 않는다 (`PROD_…` 도 잡힌다). 구분자(`_` `-`)는 적어도 되고 안 적어도 된다.
- `FOLDER_PREFIXES` 를 비우면 고르는 자리 자체가 화면에서 사라진다.
- 걸러서 폴더가 0~1개면, 안내 문구가 **어떤 접두사로 보고 있는지** 함께 알려준다
  ("날짜 폴더가 없습니다" 만 보면 원인을 못 찾는다).

### 예전 설정 파일 대응

`change/config.ts` 는 커밋되지 않아 **이미 쓰던 사람의 파일에는 이 항목이 없다.**
`ensure-config.mjs` 는 기존 파일을 덮어쓰지 않으므로, 그대로 두면 import 가 깨진다.

- 화면 쪽은 `import * as` 로 읽어 **없으면 접두사 기능만 끈다** (화면은 정상 동작).
- `npm run dev` 시작 시 "config.ts 에 FOLDER_PREFIXES 가 없습니다" 안내를 한 줄 남긴다.
- 사용자 파일을 스크립트가 고치지는 않는다 — 넣어둔 값을 건드리는 위험이 더 크다.

### 고친 파일

| 파일 | 한 일 |
| ---- | ----- |
| `src/types.ts` | `FolderPrefix` 타입, `ALL_PREFIXES_ID` |
| `change/config.example.ts` | `FOLDER_PREFIXES` · `DEFAULT_PREFIX_ID` (운영/테스트/개발) |
| `src/features/settings/folderPrefix.ts` | 목록·기본값·저장/복원 (신규) |
| `server/snapshotRepository.ts` | `matchesPrefix` + 훑기 **전** 필터 |
| `server/codeRepositoryPlugin.ts` | `prefix` 쿼리 파라미터 |
| `src/api/client.ts` | `fetchSnapshots(source, prefix, refresh)` |
| `src/App.tsx` | 헤더 선택 UI, 접두사가 바뀌면 목록 다시 읽기, 안내 문구 |
| `scripts/ensure-config.mjs` | 예전 설정 파일 안내 |

### 검증

- 타입 검사 통과, 테스트 **197개 전부 통과** (`npm test`). 접두사 테스트 18개 추가 —
  판정 규칙(대소문자·중간 일치 제외)과 **실제 임시 폴더**로 거른 결과, 화면 쪽 선택/복원까지.
- 브라우저 확인: `prod_/test_/dev_` 가 섞인 폴더에서
  전체(5개) → 운영(2개) → 개발(1개, 안내 문구) 전환, 새로고침 후 선택 유지,
  요청에 `&prefix=prod` 가 실리는 것까지 확인.
- `FOLDER_PREFIXES` 를 지운 설정으로도 확인 — 고르는 자리만 사라지고 목록은 정상.

### 외부 API 변경 여부

**기존 API 는 바뀌지 않았다.** `GET /api/v1/snapshots` 에 **선택** 파라미터 `prefix` 가 하나 늘었을 뿐이고,
보내지 않으면 지금까지와 똑같이 동작한다 (응답 형태 그대로). 비교 API 2개는 손대지 않았다.

```
GET /api/v1/snapshots?mode=local&root=D%3A%2Frelease&prefix=prod
```

스펙은 [API.md](../API.md#1-스냅샷-목록) 참고.
